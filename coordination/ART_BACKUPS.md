# Tripo 替代方案

核对日期 2026-11-26。用户明确 Tripo 不可用，后续不把 Tripo 列为生产依赖。下面是经官方公开资料核对的候选，未登录用户账户、购买套餐或生成实机资产。

## 制作路线

保留 Blender 作为基础工具。用脚本制作模块化住宅、城墙、帐篷框架、陶器和重复道具，统一尺寸、原点与材质。复杂人物、服装变形和角色动画另做小样验收。Google Pro 的图像能力优先用于参考图，权益需以账户实测为准。

## 云端优先候选：Meshy

- 官方 API 支持图生 3D、多图生 3D、重拓扑、贴图、绑定与动画，可接入程序队列。
- 先使用网页或官方 Playground 测试一栋住宅及一名长袍人物，记录生成时间、返工时间、可导出格式和实际游戏画面。确认账号所在地区可访问后再决定是否付费。
- 免费网页试用与生产 API 授权不同。官方文档说明免费档可以在 Playground 用内置测试 key 试图生 3D，不能据此推断可以无限免费调用生产 API。
- 条款 3.2 说明免费输出按 CC BY 4.0 提供，要求署名；付费计划对输出的权利另有规定。素材记录须保存生成时间、套餐、参考图来源和适用条款。
- 接入时选择仍受支持的模型，避免使用已退役的 `lowpoly`；官方当前提示 `meshy-7` 三维生成将于 2026-12-31 退役。先核对模型目录后固定版本。

来源：[图生 3D API](https://docs.meshy.ai/en/api/image-to-3d)、[开发者平台](https://docs.meshy.ai/en/api/developer-platform)、[条款](https://www.meshy.ai/terms-of-use)。

## 国内云端备用：腾讯 HY-3D-3.1

腾讯公告说明历史混元生 3D 2.5 与 3D 人物生成 1.0 接口已于 2026-10-20 终止全量服务，推荐迁移至 TokenHub 的 HY-3D-3.1。支持文字、图片、多视图及其他建模输入。现阶段只作为备选，尚未验证用户账号、价格、实际授权及导出质量。

接入时使用当前 TokenHub 文档，不能照旧教程绑定已下线接口。[官方服务调整公告](https://cloud.tencent.cn/announce/detail/2403)

## 本地模型暂缓

本机 `nvidia-smi` 实测 NVIDIA GeForce RTX 5060 Laptop GPU，8151 MiB 显存。Hunyuan3D-2.1 官方仓库列出形状生成 10GB、贴图生成 21GB、完整形状与贴图 29GB 的显存要求。因此不将本机直接运行完整流程作为当前主力。量化、卸载或其他轻量模型可以另做实验，但没有实测前不承诺质量或速度。

该模型使用腾讯社区许可，开放权重不等于无条件商用，也不意味着 Google Pro 自动覆盖推理服务费用。[官方仓库](https://github.com/Tencent-Hunyuan/Hunyuan3D-2.1) · [许可](https://github.com/Tencent-Hunyuan/Hunyuan3D-2.1/blob/main/LICENSE)

## 采用标准

比较三项：能否导入游戏且动作正常；修改后能否保持统一的古代近东美术风格；每件合格资产的总费用与人工返工时间。测试合格后才接入正式资产任务。云服务全部不可用时，先以 Blender 可控几何资产继续建筑、经营和战斗原型工作。
